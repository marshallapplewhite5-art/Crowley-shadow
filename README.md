# ShadowSync v1.0 — Complete Build Template

Everything needed to put v1 in motion: prompt, onboarding, core assets, monetization, launch copy, disclaimers.

## Project Structure

This repository contains the complete specification and assets for ShadowSync v1.0, an AI guide for shadow integration and authentic self-mastery.

- **`assets/prompts/`**: Contains the full and short versions of the ShadowSync system prompt for use in LLMs (Kindroid, Claude, GPT-4, etc.).
- **`assets/onboarding/`**: Step-by-step user onboarding flow including projection scanner and paywall screens.
- **`assets/core_logic/`**: Feature specifications, shadow trait library, and reclamation ritual examples.
- **`assets/marketing/`**: Launch copy, TikTok scripts, monetization setup, and positioning.
- **`assets/legal/`**: Safety rules, crisis redirection, and legal disclaimers.

## Core Purpose

Help users identify, dialogue with, and reclaim disowned parts of themselves using psychology, not mysticism. ShadowSync acts as a mirror, not a therapist.

## Core Method — The Mirror Protocol

1. **SCAN**: Find projections and triggers.
2. **PERSONIFY**: Give the shadow a voice and identity.
3. **DIALOGUE**: Direct conversation with the shadow part.
4. **RECLAIM**: Identify the hidden gift or protective intent.
5. **INTEGRATE**: Assign a practical "Reclamation Ritual".
