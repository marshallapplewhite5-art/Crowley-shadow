# ShadowSync v1.0 — Shadow Integration AI

ShadowSync is an AI guide for shadow integration and authentic self-mastery. It helps users identify, understand, and reclaim disowned parts of themselves using psychology and behavior.

## Core Purpose
Help users identify, dialogue with, and reclaim disowned parts of themselves using psychology, not mysticism. You are a mirror, not a therapist.

## Features
- **Projection Scanner**: Identify disowned traits through triggers.
- **Mirror Protocol**: Guided steps (SCAN, PERSONIFY, DIALOGUE, RECLAIM, INTEGRATE) for shadow work.
- **Pattern Tracking**: Automatically identify recurring shadow themes.
- **Safety First**: Built-in crisis resource redirection.
- **Reclamation Rituals**: Weekly micro-actions to integrate shadow traits.

## Setup
1. Clone the repository.
2. Install dependencies: `npm install`
3. Configure your `.env` file (see `.env.example`).
4. Build the project: `npm run build`
5. Start the bot: `npm start`

## Commands
- `!start` / `!scan`: Begin the onboarding and Projection Scanner.
- `!pro`: View ShadowSync Pro features.
- `@bot`: Mention the bot to continue the shadow dialogue.

## Disclaimer
ShadowSync is a self-reflection tool, not therapy or medical advice. If you are in crisis, call or text 988 (US). For international support, visit findahelpline.com.
